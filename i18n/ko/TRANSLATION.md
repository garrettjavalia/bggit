# 한국어 번역 기준

원문은 저장소 루트의 `src/`, 번역문은 `i18n/ko/src/`에서 관리합니다. 원문을 번역문으로 덮어쓰거나 원문 업데이트를 번역 디렉터리에 일괄 복사하지 않습니다. 원문 기준 커밋과 파일 해시는 `upstream-baseline.json`에 유지합니다.

## 문체와 용어

원문의 친근한 설명과 농담을 살리되, 한국어 본문은 자연스러운 합니다체로 작성합니다. 질문은 `-나요?/-까요?`, 함께 해 보는 실습은 `-해 봅시다`, 직접 지시는 `-하세요/-해 보세요`처럼 문장의 기능에 맞게 씁니다. 영어의 모든 `you`를 기계적으로 옮기지 않고, 독자를 직접 부를 필요가 있을 때만 `여러분`을 씁니다. 저자는 `저/제가`, 저자와 독자가 함께 밟는 추론은 `우리`로 표현합니다.

Beej 특유의 짧은 문답, 반전, 과장, 괄호 속 농담과 자조는 같은 위치와 강도로 살립니다. 특히 짧은 질문과 답은 가능하면 독립 문장으로 두어 설명의 박자를 유지합니다. 저자가 모르는 점, 개인적 취향, 앞선 설명의 단순화를 인정하는 대목도 지우지 않습니다. 다만 원문에 없는 사투리, 반말, 유행어, 대중문화 비유나 억지스러운 ‘미국 아저씨’ 말투를 새로 넣지는 않습니다.

농담 다음의 기술 설명은 정확하고 단정하게 전환합니다. 보안, 데이터 손실, 충돌과 복구에 관한 경고는 조건, 필요한 행동, 가능한 결과를 모두 보존하고 원문의 강도로 씁니다. 절차, 주의 사항, 예외, 반복, 각주를 매끈하게 만든다는 이유로 생략하거나 요약하지 않습니다.

| 원어 | 한국어 |
|---|---|
| repository / repo | 저장소 |
| commit | 커밋 |
| branch | 브랜치 |
| working tree / worktree | 작업 트리 |
| staging area | 스테이징 영역 |
| remote | 원격 저장소 |
| remote tracking branch | 원격 추적 브랜치 |
| merge | 병합 |
| conflict | 충돌 |
| rebase | 리베이스 |
| checkout | 체크아웃 |
| pull request | 풀 리퀘스트 |
| submodule | 서브모듈 |
| tag | 태그 |

명령어, 옵션, 경로, 예제 파일명, 브랜치 이름과 커밋 메시지, 터미널 출력은 원문 그대로 유지합니다. 실행 예제를 그대로 따라 할 수 있도록 코드 블록을 보존하고 필요한 설명은 본문에서 번역합니다. UI 화면과 그림 속 명령·식별자도 원문과 대조할 수 있도록 유지합니다.

## 문서 구조

제목과 링크의 표시 문구는 번역하되, URL과 내부 링크 대상은 유지합니다. 영어 제목에서 자동 생성되던 앵커는 명시적인 `{#id}`로 고정하여 제목 번역 후에도 기존 링크가 작동하도록 합니다. 전처리 매크로와 각주 식별자를 보존합니다. 색인 키는 명령 및 영어 용어로 검색할 수 있도록 원문의 키를 유지합니다.

## 검수와 상태

자동 번역 초안은 완역·출판 검수를 마친 번역과 구별합니다. `upstream-baseline.json`의 `translated-draft`는 본문 번역 초안이 작성된 상태이며, 사람의 전수 감수를 뜻하지 않습니다. 파일 편집 여부만으로 완료 상태를 추론하지 않습니다.

검수에서는 원문과 번역문의 절 구조, 코드 블록, 링크 대상, 각주와 색인 키를 비교하고, HTML 링크 검사 및 한국어 PDF 렌더링을 확인합니다. 원문 업데이트를 번역에 반영한 뒤에도 이 검사를 반복합니다.
