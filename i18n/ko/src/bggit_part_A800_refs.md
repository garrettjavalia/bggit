**"당신 책은 별로예요. 다른 참고 자료는 없나요?"**

더 있습니다! 인터넷에서 Git 책 추천을 검색해 찾았습니다. 이 가운데 제가 사용해 본 것은 매뉴얼 페이지와 *Pro Git*뿐입니다.

[i[Reference Material-->`man` pages]]

* **매뉴얼 페이지**
  * 시스템에 매뉴얼 페이지(역사적으로 "man pages"라고 부릅니다)가 설치되어 있다면, 아마 설치되어 있을 텐데, 명령줄에서 곧바로 특정 Git 명령에 관한 도움말을 볼 수 있습니다.

    예를 들어 `git config`에 관해 알고 싶다면 다음과 같이 입력합니다.

    ``` {.default}
    $ man git-config
    ```

    ("git"과 "config" 사이의 빼기 기호가 필요한지는 시스템에 따라 다를 수 있지만, 이 표기가 작동하지 않는 곳은 본 적이 없습니다.)

    매뉴얼을 연 뒤에는 화살표 키, 스페이스 바, Page Up/Down 키로 이동할 수 있을 것이고, `q`나 `Escape`를 누르면 종료될 것입니다. 시스템에서 사용하는 페이저에 따라 다릅니다.

    이 매뉴얼 페이지들은 내용이 아주 방대하고 쉽게 읽히는 편은 아닙니다. 하지만 정보는 모두 들어 있습니다! 아래의 _Git 참고 설명서_에서도 볼 수 있습니다.
